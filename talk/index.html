the readme's insight

load a gem
without loading
rubygems.

# the usual way — resolve the path every launch (~45ms)
require 'rubygems'
gem 'colorls'
require 'colorls'

# if you already KNOW the path, you don't need the resolver
RUBYLIB=.../colorls/lib \
  ruby --disable-gems -e "require 'colorls'"
every CLI pays two taxes

1 — resolver tax

find & activate the gems

2 — code-loading tax

actually load all that Ruby

tax 1 — resolver

recomputing a
known answer.

precompute it →
skip rubygems entirely.

fast even for a single cold run

tax 2 — code-loading

real work,
every process.

you can't precompute it.

you can only keep it hot.

← this is Spring's lever

ready = both.

freeze the paths. keep the process warm.
for every tool you type.

    ready_by -e '…irb source…' "$@"
}
